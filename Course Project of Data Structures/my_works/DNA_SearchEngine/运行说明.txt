DNA 序列片段错配容错检索引擎

运行方式：进入 release\DNA_SearchEngine，双击 DNA_SearchEngine.exe。
请保留 EXE、DLL 文件以及各插件目录的相对位置，不要只复制 EXE。

建议操作顺序：
1. 可分别生成参考基因组和 Reads，也可导入 FASTA/纯文本数据。
2. 设置参考长度、K-mer 长度、最大错配数、Read 长度和 Reads 数量。
3. “生成参考基因组”只生成新的 Reference，并清除旧 Reads、索引和结果。
4. “随机生成 Reads”根据当前 Reference 和参数生成 Reads，不建立索引。
5. 点击“建立索引”为当前 Reference 构建 K-mer 哈希索引；同一份
   Reference 可重复建立索引，每次都会更新建索引耗时和哈希负载。
6. 点击“检索当前 Read”或“高通量批量检索”。检索不会自动建立索引；
   未建立索引，或 Reference、K 变化导致索引失效时，必须先点击
   “建立索引”。
7. Reads 列表可单击选择，双击后直接执行该 Read 的单条检索。
8. 全局概览显示全部成功区域，点击色块或结果表可跳转到对应位置。
9. 局部沙盘支持拖动、水平滚动、Shift+滚轮平移和 Ctrl+滚轮缩放。
10. 选中 Read 后显示逐碱基连接关系；错配位置使用黄色和红色突出显示。
11. 精确详情显示 Reference、Read、比对关系、碱基替换和绝对位置。
12. “导出结果”生成带 UTF-8 BOM 的 CSV 文件。CSV 使用中文列名：
    Read编号、序列、匹配排名、匹配位置、汉明距离、错配详情、状态、
    候选位置数、耗时（微秒）。检索耗时保留两位小数。

导入、数据生成、索引构建、检索完成和错误信息会以左下角 Snackbar
显示；多条提示可向上堆叠。成功提示约 1.5 秒、错误提示约 2 秒后
自动向上淡出；短时间内重复出现的相同提示会复用现有 Snackbar。

参数范围：
- 参考基因组长度：2000-5000 bp。
- Read 长度：20-150 bp。
- K-mer 长度 K：2-10。
- 允许错配数：0-2。
- Reads 数量：1-50 条。

默认参数：参考基因组 3000 bp，Read 30 bp，K=6，允许错配数 2，
Reads 数量 50 条。

随机生成 Reads 时会读取界面当前的 K，保护每条 Read 的前 K 位种子；
1-2 个随机突变只会出现在 [K, Read 长度-1] 范围内。外部导入的 Reads
保持文件原始内容，不执行种子保护。

文件格式：
- 参考基因组：FASTA 或仅含 A/T/C/G 的纯文本。
- Reads：FASTA，或每行一条仅含 A/T/C/G 的纯文本序列。

随附导入测试文件：
- test_reference.fasta：固定随机种子生成的 3000 bp FASTA 参考基因组，
  用于测试“导入参考基因组”以及 FASTA 标题、多行序列解析。
- test_reads.txt：与上述 Reference 配套的 50 条纯文本 Reads，每行一条，
  每条长度 30 bp；该文件按默认 K=6 生成，所以前 6 位种子保持不变，
  种子后含 1-2 个替换突变。程序随机生成时始终保护界面当前的前 K 位；
  用于测试“导入 Reads”、索引构建、单条检索和批量检索。
- 使用这组文件时请保持默认 K=6、允许错配数=2、Read 长度=30。
  Reference 长度和 Reads 数量会以实际导入文件内容为准。
